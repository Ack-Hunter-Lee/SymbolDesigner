# 图元锁定（IsLocked）功能实现计划

## Context

SymbolDesigner 目前没有"锁定图元"能力。用户希望：**锁定后的图元仍可选中，但禁止移动与编辑**。用户已确认三项设计决策：

1. **删除保护**：`DeleteSelected` / `ClearAll` 跳过锁定图元（锁定即不可破坏）
2. **锁定开关**：放属性面板顶部（复选框），始终可点，其余编辑控件锁定时禁用
3. **组锁定**：多选时切换锁定对整体生效（复用现有外观属性批量同步机制）

## 语义定义

- `IsLocked=true` → 仍可点击选中（单选/多选/框选正常）
- 禁止：拖动移动、方向键微移、多选整体平移、缩放手柄、顶点/轮廓/带宽编辑、属性面板修改、格式刷应用、布尔/约束几何修改、删除、被清空
- 撤销：IsLocked 变化与其它属性面板编辑一致，走现有撤销快照（验证即可）

## 实施步骤

### 1. 模型层：新增属性
- `Models/PrimitiveItem.cs`：加 `[ObservableProperty] private bool _isLocked;`（参照 `IsVisible` 写法，L215-224）

### 2. 序列化：DTO + 映射
- `Models/SymbolProject.cs`：`PrimitiveItemDto` 加 `public bool IsLocked { get; set; }`（旧工程缺省 false，加载兼容）
- `ViewModels/SymbolDesignerViewModel.Persistence.cs`：`ToDto`（L206 附近 IsVisible 旁）加 `IsLocked = p.IsLocked`；`FromDto` 对应读取

### 3. CLI：字段白名单
- `SymbolDesigner.Cli/EditFields.cs`：白名单加 `"isLocked"`（bool 转换已支持）——Agent 可 `--set isLocked=true` 锁定/解锁

### 4. 交互拦截（核心）

**拖动移动**
- `Views/DraggablePrimitive.cs` `OnDragDelta`（L66-110）方法开头（取到 item 后、ArrayOwner 判断前）加：`if (item.IsLocked) return;`
  - 注意**不能**在 `OnDragStarted` CancelDrag——那会吞掉点击导致无法选中。在 DragDelta 早退，拖动无位移 → 手势结束 `HorizontalChange≈0` → Click 正常触发 → 仍可选中

**多选平移 / 微移**
- `ViewModels/SymbolDesignerViewModel.SelectionScale.cs`
  - `TryMoveMultiSelection`（L254-264）：`foreach` 内跳过 `p.IsLocked`
  - `MoveSelection`（L271-295）：targets 过滤 `!p.IsLocked`

**缩放手柄**
- `SelectionScale.cs` `RefreshScaleSelectionHandles`（L71-117）：选中集含锁定图元时不显示缩放手柄（防误缩，混合选择时整体降级为无手柄）
- `BeginScaleSelection` / `ApplyScale`（L299-422）：加守卫跳过锁定项（纵深防御）

**顶点/轮廓/带宽编辑**
- `ViewModels/SymbolDesignerViewModel.Handles.cs` `UpdateVertexPosition`（L41-85）：开头 `if (SelectedItem?.IsLocked == true) return;`
- 各 `Refresh*Handles`（Vertex/Segment/OutlineCorner/BandWidth/Ring/Pie）开头：`if (SelectedItem?.IsLocked == true) return;`（锁定时不渲染手柄）

**删除 / 清空**
- `ViewModels/SymbolDesignerViewModel.Editing.cs`
  - `DeleteSelected`（L346-377）：`toRemove` 过滤掉 `IsLocked`；若过滤后为空则 no-op
  - `ClearAllCore`：从 `Primitives` 快照中跳过 `IsLocked`

**格式刷**
- `ViewModels/SymbolDesignerViewModel.FormatPainter.cs` `ApplyFormatPainterTo`：目标 `IsLocked` 时跳过

**布尔 / 约束几何命令**
- 对应 command 方法（布尔运算、几何约束应用）入口加守卫：参与图元 `IsLocked` 时 no-op（实现时按搜索到的命令逐点加，保持轻量）

**组锁定广播**
- `Editing.cs` `OnSelectedItemPropertyChanged`（L219-296）：`IsLocked` 变化且 `MultiSelected.Count > 1` 时复用 `SyncAppearanceToMultiSelected`（L314-325 反射机制）广播到其余成员（不加入 `IsAppearanceProperty` 集，单独分支处理，避免语义混淆）

### 5. UI：属性面板

**锁定开关**
- `Views/SymbolDesignerView.xaml` 属性面板选中项信息区（HasSelectedItem 门控容器内、可编辑控件区之外）加 `CheckBox`：`IsChecked="{Binding SelectedItem.IsLocked, Mode=TwoWay}"`，文案"锁定"，始终可点

**禁用可编辑区**
- 属性面板各编辑分区（位置/尺寸、旋转、外观线条/填充等）根容器加 `IsEnabled="{Binding SelectedItem.IsLocked, Converter={StaticResource InverseBool}}"`

**转换器**
- 新增 `Converters/InverseBoolConverter.cs`（IValueConverter，取反）；在 SymbolDesignerView.xaml 资源区注册（与现有 BoolToVis 等并列）

### 6. 视觉反馈（v1 从简）
- 不新增画布叠加装饰；锁定状态通过属性面板复选框体现。后续可迭代加"锁图标/不同选中描边"（本次不做）

## 验证

1. `dotnet build SymbolDesigner/SymbolDesigner.csproj`（退出码 0 + 0 错误）
2. GUI 手工验证：
   - 画几个图元 → 多选 → 勾选锁定 → 全部变锁定（组广播生效）
   - 点选锁定图元：仍可选中；拖动无位移；方向键无响应；无缩放手柄、无顶点手柄
   - 属性面板编辑区置灰不可改；锁定复选框本身可操作
   - 选中锁定图元按删除 → 不动；清空画布 → 锁定图元保留；解锁后可删
   - 保存工程 → 重开 → IsLocked 保持
3. CLI 验证：
   - `sym edit <proj> --id <id> --set isLocked=true` → exit 0
   - `sym info` 确认字段；`sym render` 出图正常（锁定不影响渲染）
   - 改回 `isLocked=false` 可解锁
4. 撤销验证：勾/取消锁定后 Ctrl+Z 能恢复
